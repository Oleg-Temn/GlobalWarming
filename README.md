# GlobalWarming
Это проект телеграмм-бота, рассказывающего про глобальное потепление

## Моя идея проекта:
Я хочу иметь бота, который будет давать различные факты о экологии планеты и глобальном потеплении
> он будет рассказывать причины и последствия,
> он будет рассказывать что такое глобальное потепление,
> он будет давать полезные советы о заботе о природе,
> будет иметь встроенную мини-игру
> будет иметь красивый дизайн
